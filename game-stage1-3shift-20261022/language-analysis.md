## 如何解读

- 低温 Thinking 纯文字题的综合分：中文 88.73 → 83.44 → 75.20，英文 92.43 → 85.32 → 78.16。
- 同一设置下，500 的64道中英纯文字题中有16道未解析到独立 final，1500 增至48道。原始思考文本中可能仍有答案；评分已依原规则检查原文，但对交付失败限制指令/完整性分，不能把综合分下降全解释成知识遗忘。
- 低温 NoTags 纯文字题：中文综合分 93.73 → 94.65 → 93.48，英文 93.22 → 94.78 → 95.13，整体稳定。
- 高温 Thinking 中文语言项 84.09 → 78.00 → 64.34，确有输出语言稳定性恶化。高温 NoTags 英文纯文字题也从综合92.46降至82.61，应与低温结果区分。
- 这是一组固定小样本和单seed结果，不等同大规模通用能力、完整公开benchmark或因果结论。
